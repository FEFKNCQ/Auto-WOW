# 建号流程界面识别与异常处理细则

配合 `SKILL.md` 主状态机使用：记录每个界面的识别特征、按钮位置、已知坐标坑和异常处置。

**所有角色配置都来自用户开始前的逐项选择**：规则集、阵营、种族、职业、体型/外观、姓名与备选名。凡有选项的字段，Agent 必须把该层全部合法选项列给用户；本文件不提供任何默认值。旧版本中的固定配置（部落 / 男性 / 亡灵 / 圣骑士、「慌啥子嘛 / 慢慢来」）已废弃。

| 字段 | 必须列出的全部选项 |

| 种族（部落） | 兽人、亡灵、牛头人、巨魔、塑风者天裔（需天裔英雄包） |

| 模型精度 | 高清（HD）、标清（SD） |
| 姓名 | 主名 + 可选副名，另请用户提供 1-2 个备选名 |

## 创建后能否修改（向用户确认时要提醒）

- **不可修改**：规则集、阵营（PVP 锁）、种族、职业、天裔分支。
- **可修改**：体型（性别）、发型/肤色等外观、HD/SD 模型、幻化开关、天赋专精、副名在姓名板的显示。

因此在开始前必须让用户逐项确认规则集/阵营/种族/职业；外观选错可在理发店补救，不必过度纠结。

## 界面顺序与识别特征

| 阶段 | 界面 | 识别特征 | 动作 | 等待 |
|------|------|----------|------|------|
| 0 | 战网规则集选择 | 列出普通/PVP/RP/RP-PVP/硬核 | 按用户所选点选并确认 | 按界面反馈 |
| 1 | 登录界面 | 中间出现「重新连接」按钮 | 点击「重新连接」 | 4 秒 |
| 2 | 阵营 / 规则页 | 可见规则与阵营选项，右下角「选择」 | 核对规则与阵营，点「选择」 | 4 秒 |
| 3 | 角色创建界面 | 左右阵营列、顶部性别体型区、底部职业排 | 阵营 → 种族 → 职业 | 每步约 1 秒 |
| 4 | 外观 / 命名入口 | 右下角「自定外观」箭头 | 点击进入外观/命名页 | 约 1 秒 |
| 5 | 外观页 | 顶部中间的体型 1/2、HD/SD 开关、发型肤色等 | 按用户所选设置体型与模型精度 | 约 1 秒 |
| 6 | 命名界面 | 主名、副名两个输入框 | 填入用户主名/副名；失败依次换备选名 | 约 1 秒 |
| 7 | 完成提交 | 右下角【完成】 | 点击提交 | 等待结果弹窗或完成界面 |

## 角色创建界面定位

- **不要依赖固定序号或固定头像位置**：不同规则集、阵营、分辨率下职业排和种族头像顺序会变。
- 每次点击前先截屏，按当前帧 **0–1000 归一化比例**读坐标，辨认文字 / 头像 / tooltip，确认选中项后再进入下一步。
- **阵营与种族**：先确认处于用户所选阵营列，再在该列找到用户指定种族头像（部落列找兽人/亡灵/牛头人/巨魔/塑风者天裔；联盟列找人类/矮人/暗夜精灵/侏儒/高阶会天裔）。
- **职业**：在底部职业排按图标文字/提示找到用户所选职业，不以「从左数第几个」为准。
- **体型（性别）**：外观页顶部中间的「体型 1 / 体型 2」按钮，选用户确认的那一个；切换后截屏确认模型变化。
- **HD / SD**：按用户所选切换模型精度；只影响外观与动作精度。
- **其他外观**：默认不动；用户有明确偏好时调整并截屏确认。

## 已知坐标坑

- **第三次后退按钮偏上点不到**：前两次后退按左下角按钮常规位置点击；第三次后退时，点击位置在按钮可见区域内往下移一点点，避免落在按钮上沿之外。
- 坐标一律以当前截屏帧为准，禁止硬编码像素；窗口大小变化后位置会偏移。

## 等待节奏

- 普通步骤之间间隔约 1 秒，避免连点导致界面未响应。
- 重新连接后等 4 秒；规则/阵营选择后等 4 秒；不平衡回退完成后等 20 秒，确认回到登录界面再开始下一轮。
- 等待期间不重复点击同一按钮。

## 异常处置

- **界面未按预期跳转**：先截屏重读当前界面，判断停在哪一阶段，再决定下一步；不要盲目继续点。
- **卡在同一界面**：确认按钮是否被弹窗遮挡；有弹窗先处理弹窗，再操作底层界面。
- **误选阵营 / 种族 / 职业 / 体型 / 规则集**：进入命名界面之前可返回修改；已提交且属于不可修改项时按失败流程后退重来或停下报告用户。
- **用户选择不在合法选项内**（阵营无该种族、种族无该职业、天裔未解锁）：停下报告具体缺项，请用户重新选择，不要自行换成别的。
- **名称不可用 / 已存在 / 含非法字符 / 过长 / 违反 RP 命名规范**：按用户给的备选名顺序依次尝试，每次重试前重新截屏确认仍在命名界面；备选名全部失败则停下报告，不要自己编名字。
- **出现非“阵营人口不平衡”的其他弹窗**：先截屏识别弹窗文案，能识别确定/取消类按钮再处理；无法判断时停下报告，不要乱点。
- **不要点窗口右上角关闭按钮**；流程中断后从登录界面重新进入即可。

## 重试循环判据

- **阵营人口不平衡**：确定 → 后退两次 → 第三次下移点击后退 → 等 20 秒 → 回到步骤 1。每一轮都重新截屏确认界面状态，配置与名字队列沿用用户最初的选择。
- **名称不可用**：换下一个备选名重试当前命名步骤；主名和所有备选名都失败才停下报告。
- 循环直到无弹窗、成功提交，且角色配置与用户确认结果一致；不限制重试次数。

## 成功判定

- 不再出现“阵营人口不平衡”弹窗，角色进入角色选择列表或角色创建完成界面。
- 逐项核对：规则集、阵营、种族、职业、体型、HD/SD、主名、副名（外观有偏好时一并核对）都与用户选择一致；任一项不一致不得报成功。
